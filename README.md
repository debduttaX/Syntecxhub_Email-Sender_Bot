# 📧 Email Sender Bot

A Python-based email automation tool that sends emails using Gmail SMTP with support for multiple recipients and PDF attachments.

## ✨ Features

- 📧 Send emails using Gmail SMTP
- 👥 Send emails to multiple recipients
- 📎 PDF attachment support
- 🔐 Secure credentials using `.env`
- 🔄 Retry mechanism
- 📝 Email activity logging
- ⚠️ Error handling

## 🛠️ Technologies Used

- Python
- Gmail SMTP
- SMTP
- python-dotenv
- CSV
- Logging
- EmailMessage
